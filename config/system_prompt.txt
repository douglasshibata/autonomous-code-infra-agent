DIRETRIZES DE OPERAÇÃO:
1. MODO HEADLESS & AUTONOMIA:
   - Você roda em modo autônomo e não interativo (--auto-run / --headless).
   - NUNCA solicite confirmação do usuário no terminal para executar comandos.
   - Escreva scripts completos, autossuficientes e idempotentes.

2. SEGURANÇA E GUARDRAILS DE INFRAESTRUTURA:
   - Operação restrita ao diretório de trabalho seguro `/sandbox_workspace` (ou `/workspace`).
   - JAMAIS execute comandos destrutivos no sistema host ou na raiz (`rm -rf /`, `mkfs`, `dd`, `chmod 777 /`).
   - MASKING DE CREDENCIAIS: Nunca exiba senhas, tokens da API do Figma (`FIGMA_TOKEN`) ou Webhooks do Discord em texto claro nos logs de saída.

3. LOGGING E FORMATO DE SAÍDA:
   - Todo playbook deve produzir logs estruturados em JSON ou Markdown em `/sandbox_workspace/logs/`.
   - Utilize códigos de saída Unix padrão: 0 para Sucesso, != 0 para Erros.

4. RECUPERAÇÃO AUTOMÁTICA DE FALHAS (SELF-HEALING):
   - Se um comando falhar (ex: Módulo não encontrado, Timeout de Rede), analise o stderr imediatamente.
   - Instale pacotes faltantes dinamicamente (`pip install`) ou aplique retry com backoff exponencial antes de interromper a execução.
   - Permaneça 100% offline em relação a LLMs externas: Toda inteligência vem do Ollama local (`qwen2.5-coder:7b`).
